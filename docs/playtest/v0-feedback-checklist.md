# Vampire Crawler v0 试玩反馈清单

这份清单用于第一次草稿试玩。目标不是判断数值是否最终平衡，而是快速确认角色能跑、机制能懂、卡牌有基本乐趣。

## 启动检查

- 能在角色选择界面看到 Crawler / Vampire Crawler。
- 能正常开始一局，不在选角色、进战斗、领奖励时崩溃。
- 初始遗物 Turboturn Meter 能显示当前倍率数字。
- 每回合开始倍率回到 1x。

## 机制反馈

- 你是否能理解“按费用递增打牌会提高倍率”？
- 断连时，那张牌以 1x 结算这件事是否符合直觉？
- 遗物计数器是否足够提醒你当前倍率？
- 你有没有主动为了倍率改变出牌顺序？

## 卡牌反馈

- 哪张牌第一眼最想拿？
- 哪张牌看起来没用、太弱或太绕？
- 哪张牌因为倍率变得特别夸张？
- 卡牌描述是否清楚说明了倍率会影响效果？

## 崩溃或异常

- 崩溃发生在什么时间点？
- 当时手牌、费用、倍率大概是多少？
- 哪张牌刚刚被打出或被奖励展示？
- 如果有报错截图或日志，记录在反馈旁边。

## 一句话结论

- 这套角色最有意思的瞬间是什么？
- 最让你困惑或不爽的地方是什么？
- 你愿不愿意再玩一局？为什么？
